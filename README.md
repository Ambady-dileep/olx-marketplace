# OLX Marketplace Clone

A simple OLX-like marketplace web application built with **React**, **Vite**, **Tailwind CSS**, and **Firebase** (or mock backend). This project is for learning and experimentation purposes.

---

## Features

- Add, view, and browse products.
- Each product has:
  - Name
  - Price
  - Description
  - Address
  - Image upload
- Responsive design with **Tailwind CSS**.
- Basic client-side form validation.
- Recommended VS Code extensions included for a better dev experience.

---

## Tech Stack

- **Frontend:** React, Vite, Tailwind CSS
- **Backend:** Firebase Firestore (or mock data for frontend-only)
- **State Management:** React hooks
- **Version Control:** Git & GitHub
